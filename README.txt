# Trust City Township Website

Static HTML/CSS/JavaScript home page using the supplied Trust City logo and township layout.

## Run
Open `index.html` in a browser, or use VS Code Live Server.

## Important
1. Replace the placeholder WhatsApp number `918000000000` in `index.html` and `script.js` with the actual project WhatsApp number.
2. Connect the enquiry form to your backend/CRM/email service before production.
3. Verify all legal/project claims and contact details before publishing.
4. Add the remaining pages:
   - about.html
   - project.html
   - amenities.html
   - location.html
   - gallery.html
   - blog.html
   - contact.html
